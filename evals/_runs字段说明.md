## 〇、CSV 通用约定

- **编码**：UTF-8 无 BOM
- **换行**：LF
- **分隔符**：英文逗号 `,`
- **引号**：含逗号或换行的字段必须用 `"` 包裹；内部双引号转义为 `""`
- **多值字段**：`触及端` 用英文分号 `;` 分隔（如 `admin;cockpit`）
- **空值**：写 `-`（不写空字符串），表示"不适用"或"跳过"
- **append-only**：禁止删除已有行；纠错只能追加新行并在备注列标注

| 17 | `实际改动文件数` | int | `08-修复历史.md` 末轮汇总 / 或 git diff 统计 | 与字段 8 对比可看 A3 估算准度 |
| 18 | `备注` | string | retrospector 自动 + PM 可补 | 含异常情况，如 `hotfix途中插入` / `字段4纠错` 等 |

## 二、衍生指标（不入 CSV，由 `pipeline-evaluator` 计算）

- **A3 估算偏差** = `(实际改动文件数 - A3_声明改动文件数) / A3_声明改动文件数`
- **A1 一遍过率** = `count(A1_轮数 == 1) / total`
- **A4 触发 A5 率** = `count(A4_结论 == "触发A5") / total`
- **A7 一遍过率** = `count(A7_打回轮数 == 0) / total`
- **平均 Codex 提问数**（按 类型 / 触及端 分组）

这些衍生指标在 `weekly/<YYYY-WW>-周报.md` 中呈现。

