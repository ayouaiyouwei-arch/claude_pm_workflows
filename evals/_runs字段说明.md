## 〇、CSV 通用约定

- **编码**：UTF-8 无 BOM；**换行**：LF；**分隔符**：英文逗号 `,`
- **引号**：含逗号或换行的字段必须用 `"` 包裹；内部双引号转义为 `""`
- **多值字段**：`触及端` 用英文分号 `;` 分隔（如 `admin;backend`）——**禁用 `+`**
- **空值**：写 `-`（不写空字符串），表示"不适用"或"跳过"
- **append-only**：禁止删除已有行；纠错只能追加新行并在备注列标注
- **写入时校验（v1.1 起强制）**：每次 append 后必跑 `bash scripts/validate-evals-csv.sh runs --last`，失败不准报完成

## 二、衍生指标（不入 CSV，由 `pipeline-evaluator` 计算）

- **A3 估算偏差** = `(实际改动文件数 - A3_声明改动文件数) / A3_声明改动文件数`
- **A1 一遍过率** = `count(A1_轮数 == 1) / total`
- **A2 一遍过率** = `count(A2_结论 == "通过") / total`
- **A4 触发 A5 率** = `count(A4_结论 == "触发A5") / total`
- **A7 一遍过率** = `count(A7_打回轮数 == 0) / total`
- **平均 Codex 提问数**（按 类型 / 触及端 分组 · 排除 `-` 行）
- **A5 推翻率** = `count(A5_PM裁决 == "推翻") / count(A5_是否触发 == "是")`（v1.1 新增）
- **分路径分布与分路径逃逸率**（× `escapes.csv` 关联 · v1.1 新增）
- **patch 前后切片**：按 `patch水位` 分组对比核心率值（v1.1 新增 · 样本 < 3 标"样本不足"）
- Loop 类衍生指标见 `_loops字段说明.md § 三`；逃逸类见 `_escapes字段说明.md § 四`

这些衍生指标在 `weekly/<YYYY-WW>-周报.md` 中呈现。
