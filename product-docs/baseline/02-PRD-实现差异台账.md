# 02 · PRD-实现差异台账

> 🔧 项目无关骨架版 · 起始为空，由 `log-diff-entry` skill 追加。
> 用途：登记"PRD 期望"与"代码实现"之间发现的差异（DIFF），跟踪到裁决。

## 一、状态定义（8 类）

`待裁决 / 修复中 / 已修复 / 不修复 / 转变更(CHG) / 已发布 / 暂缓 / 作废`

## 二、差异登记表

> 每条 DIFF 用纵向键值块登记（编号 / 标题 / 发现日期 / 影响范围 / 期望 / 实际 / 状态 / 裁决截止 / 关联 CHG）。
> 对齐 P007：发现差异 ≤ 14 天内裁决。
