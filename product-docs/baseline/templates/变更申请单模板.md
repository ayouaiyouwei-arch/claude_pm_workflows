# 变更申请单模板（CHG-XXX）

> 🔧 项目无关骨架版 · 示例均为占位 · 项目专属配置见 PROJECT-PROFILE.md

> 创建新变更时，请**完整复制本模板**，禁止删字段、禁止改字段顺序。所有字段填写完成后追加到 `baseline/03-产品变更登记.md` 表格末尾，并在本目录或附件中保存详情页。

## 1. 基本信息

| 字段 | 值 |
|---|---|
| **编号** | CHG-XXX（顺延） |
| **类型** | 新增功能 / 修改功能 / 删除功能 / 接口扩展 / 字段调整 / 枚举调整 |
| **模块** | （与 `02-页面-产品-代码对照矩阵.md` 一致） |
| **页面 / 范围** | `/admin/<模块>` 或全局 |
| **状态** | 申请中（默认） |
| **优先级** | P0 / P1 / P2 |
| **期望生效基线** | B1.x.x |

## 2. 业务说明

| 字段 | 值 |
|---|---|

## 3. 影响分析

| 维度 | 是否受影响 | 说明 |
|---|---|---|
| 接口 | 是 / 否 | 新增 / 修改 / 删除哪些接口 |
| 数据库 | 是 / 否 | 新增 / 修改 / 删除哪些表 / 字段 / 索引 |
| UI | 是 / 否 | 涉及的页面、组件 |
| 权限 | 是 / 否 | 新增权限码 / 角色 |
| 算法 | 是 / 否 | 是否触达算法引擎 |
| 性能 | 是 / 否 | 性能影响（QPS / 响应时间 / 资源占用） |
| 安全 | 是 / 否 | 鉴权 / 数据权限 / 敏感信息 |
