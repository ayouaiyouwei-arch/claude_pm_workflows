# 00 · 基线管理流程

> 🔧 项目无关骨架版 · 示例均为占位 · 项目专属配置见 PROJECT-PROFILE.md

> 本文件定义基线管理的**角色 / 触发条件 / 标准 SOP / 版本递增 / 发布产物**。

---

## 一、五类角色与职责

| 角色 | 职责 |
|---|---|
| **产品负责人** | 裁决差异 / 评审变更 / 拍板基线版本号是否升 minor / major |
| **技术负责人** | 评估差异修复方案的可行性 / 评审变更的技术影响 / 联合产品负责人裁决 |
| **开发 AI**（前端 / 后端） | 提交修复 PR + 单次修复交付报告 + 必要时申请变更（CHG-XXX） |
| **测试 / 验收人** | 走 5 态 + 链路 + 接口契约 + 回写差异台账状态字段 |
| **文档维护者** | 维护基线版本登记 / 差异台账 / 变更登记 / 发布通告，更新「说明文档.md」进度 |

---

## 二、四类触发条件

| # | 类型 | 触发场景 | 处理路径 |
|---|---|---|---|
| 1 | **产品侧触发** | PRD 改稿 / 新增功能 / 删除功能 / 调整边界 | 走 `03-产品变更登记.md` 创建 CHG-XXX → 评审 → 通过 → 实施 → 纳入下个基线 |
| 2 | **实现侧触发** | 验收发现 PRD 与实现不一致 / 同步代码后发现接口变更 | 走 `02-PRD-实现差异台账.md` 创建 DIFF-XXX → 裁决 → 修复 → 回写 → 纳入下个基线 |
| 3 | **审计周期触发** | 月度 / 季度复盘发现一批已关闭差异 + 通过变更 | 调用 `.claude/skills/periodic-review/SKILL.md` → 出复盘报告 → 建议升 minor / major |
| 4 | **时间节奏触发** | 阶段性客户演示 / 季度发版节点 | 提前 1 周冻结基线，走 `04-基线刷新检查清单.md` |

## 四、版本递增规则

| 当前版本 → 新版本 | 触发条件 | 示例 |
|---|---|---|
| **patch** B1.0.0 → B1.0.1 | 已裁决差异修订 / 文案 / 字段映射调整 | DIFF-001 ~ DIFF-003 关闭后发布 B1.0.1 |
| **patch** B1.0.x → B1.0.(x+1) | 累计 ≥ 3 条已关闭差异 | 任意 3 条 P1/P2 差异打包发布 |
| **minor** B1.0.x → B1.1.0 | 已通过变更带新增功能模块 / 新增页面 | `<CHG-XXX>`「`<某新增功能>`」+ 新模块 |
| **minor** B1.x.x → B1.(x+1).0 | 累计 ≥ 3 条已发布变更 | 一组中等规模变更打包 |
| **minor（docs-only）** B1.0.x → B1.1.0 | `/init-docs` 存量文档基建全模块收口（无代码变更） | N 模块六件套+用例库建成；按 `publish-baseline`《场景 B · docs-only 特例》放宽前置（存量拆解新立 DIFF/CHG 不阻塞、不回写状态、测试轨 N/A） |
| **major** B1.x.x → B2.0.0 | PRD 大版本切换 / 业务边界扩展 / 不兼容字段重构 | PRD v2.0 发布 / 字段命名空间重构 |

## 五、发布新基线的产物清单

每次基线发布必须产出下列 5 项：

| # | 产物 | 位置 |
|---|---|---|
| 1 | **新版本登记行** | `01-基线版本登记表.md` 末尾追加（已发布行不可修改） |
| 2 | **差异台账状态回写** | 本次纳入的 DIFF-XXX → 「已关闭-纳入 B<新>」 |
| 3 | **变更登记状态回写** | 本次纳入的 CHG-XXX → 「已发布-B<新>」 |
| 4 | **发布通告** | 通过约定通道发布，文案见 `.claude/skills/publish-baseline/SKILL.md` 输出段 |
| 5 | **说明文档进度记录** | 工作空间根 `说明文档.md` 第三节追加发布里程碑 |

任意一项缺失 → **发布无效，必须补齐**。

## 六、违规与回滚

| 行为 | 判定 | 处置 |
|---|---|---|
| 修改已发布的基线行 | 严重违规 | 立即回滚 + 通报 |
| 跳过 04-基线刷新检查清单发布 | 严重违规 | 撤销发布 + 重走流程 |
| 修复完不回写差异台账 | 违规 | 退回修复人 + 重新提交 |
| 引入新能力但未登记变更 | 违规 | 退回 + 走 CHG 流程 |
| 5 类产物缺失 | 违规 | 补齐前不视为已发布 |
