# 00 · 调查方法（视觉基线）

> 本目录由 `extract-visual-baseline` skill（patch-010）自动提取 + PM 确认转正。统计口径见 § 三。

## 一、定位

`product-docs/visual-baseline/` 是 A1.5（visual-spec-author）做 UI 类需求视觉规范时的**项目风格唯一事实源**：允许色系白名单、字号/间距阶梯、组件惯例、"不引"组件库黑名单均以此为准，超出即打回。

## 二、文件清单

| 文件 | 内容 |
|---|---|
| 01-颜色清单.md | 实测色频次：中性/主色/语义色/品牌色 + 允许色系白名单 |
| 02-字号清单.md | 字号阶梯 + 典型用途 |
| 03-间距清单.md | spacing 阶梯 + 圆角/阴影惯例 |
| 04-设计系统配置现状.md | tailwind.config / 全局 CSS 变量实录 |
| 05-组件清单.md | 可复用组件 + UI 依赖 + 不引黑名单 |
| 06-token-候选推导.md | 硬编码 HEX → Tailwind class 速查 + A1.5 硬约束 |
| 07-未token化的硬编码热点.md | 高频硬编码 hex 样例文件 |
| 08-交互最佳实践参考.md | 行业通用沉淀（非提取物 · 人工校准） |

## 三、统计口径

- 扫描器：`scripts/visual-baseline-scan.py`（只读，不改源码）
- 范围：`*.tsx/.ts/.jsx/.js/.css/.vue/.html/.scss/.less`，跳过 node_modules/dist/build
- 统计：Tailwind 色 class（family-shade 聚合）、硬编码 hex/rgba、text-* 字号、CSS font-size、spacing class、CSS px、rounded-*、shadow-*、dark: 前缀、组件 import 引用、package.json UI 依赖
- 机器留档 JSON 可复跑 diff（刷新模式产 drift 报告）
