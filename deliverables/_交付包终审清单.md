# 交付包终审清单（交付前 · 跨产物勾稽）

> 🔧 项目无关骨架版 · 与 `scripts/deliverable-final-check.sh` 配套（脚本是可执行版的本清单）。

## 这道闸补什么

流水线 8 个 agent 各审**一份**产物（A2 审需求、A4 审范围、A7 审用例），打包第 8.6 步只做**机械自检**（文件数、占位符）。**没有任何环节审"这一包 11 个文件拼在一起是否自洽、够不够 Codex 直接开工"。** 跨产物 / 集成级的缺陷（接口与用例对不上、视觉门槛该删没删、编号漂移）会一路漏到 PM 灰度（交付后）才暴露——正是 `evals/escapes.csv` 里"全过仍漏"那一档。

本闸把这类缺陷**左移到打包前**（便宜得多）。

**它做什么 / 不做什么**（避免与现有环节重叠 = 避免纯成本）：

- ✅ 只查**产物之间的接缝**（客观可机检的交叉勾稽，对齐 P007 实证驱动）
- ❌ 不重审单份产物内容（那是 A2/A4/A7 的活）
- ❌ 不打主观质量分（pipeline-evaluator 才做，且分来自 PM rubric）
- ❌ 不验证"代码照做没"（dev-verify P005 / PM 灰度 P013 的活）

## 何时跑

- `/new-feature` 第 **8.6b** 步（打包收尾、Gate 3 前）——主流程已内置
- 手动：`bash scripts/deliverable-final-check.sh <交付包目录>`（例 `deliverables/2026-06-16-CHG-042-x.draft`）
- 升 `.active` 前再跑一次兜底（best-effort，不接 hook——包是逐文件构造的，always-on 会误报）

`exit 0` = 无 BLOCKER（可能有 ⚠️ WARN，PM 自行判断）；`exit 1` = 有 BLOCKER，材料未就绪，别交 Codex。

## 检查项（BLOCKER = 一票否决 · WARN = PM 判断）

| 组 | 检查 | 严重度 | 拦的缺陷 |
|---|---|---|---|
| **B1 机械完整性** | 根 .md ≥ 11、AGENTS.md / 00-导读 在、snapshot 含 ≥1 csv、02 无占位 | BLOCKER | 包结构残缺（移植并扩展原 8.6） |
| **B2 占位残留** | 冻结契约文件（01/03/04/05/06[/01.5]）不含脚手架硬占位（`<模块>`/`<填写`/`<CHG-XXX>`/`TODO` 等） | BLOCKER | 模板没填实就打包 |
| | 同上文件含疑似模板措辞（`示例均为占位`/`<某…>` 等） | WARN | 例子忘替换 |
| **B3 接口契约自洽** | 04 §一 接口清单 ⟺ §四 详细契约 **双向一致** | BLOCKER | 列了接口没契约 / 有契约没登记 |
| | 06/05 引用的接口编号必须 ∈ 04 §一 接口清单 | WARN | 接口改名/删除后，门槛/用例成死引用 |

## 读结果的姿势

- **全绿（exit 0）** → 跨产物自洽，进 Gate 3 让 PM 拍板打包/升级
- **有 BLOCKER（exit 1）** → 按报告里的文件:行号修材料，**回 `_drafts` 改还是直接改 `.draft` 包**按 `/new-feature` 第 8.8 指引；改完重跑
- **只有 WARN** → 不阻断，但每条 WARN 念给 PM 听一句业务影响（对齐 P015），PM 说"故意的"就放行

## 演进方向（先轻后重）

本清单是**轻量版**（零新增 agent，对流水线节奏 F 指标几乎无成本）。积累若干真实 `.done` 包后，用 `evals/escapes.csv` 的"全过仍漏"计数验证它确实压低了逃逸率——若验证有效且需要更深的语义审，再考虑升级为完整的 `A8 交付包终审` agent。届时把本清单作为该 agent 的硬检查基线。

**v2 候选检查项**（对抗性审查提出 · 价值真但误报面/解析成本更高，待真实包验证 ROI 后再加）：

- **枚举勾稽**：04 请求/响应用到的 `result`/`type` 枚举字面量 ⊆ 03 §3.3/§3.4 定义集（拦"04 用了 03 未定义的枚举值"）
- **模块名漂移**：05 asset_path / 04 `/api/<模块>` 段 / snapshot CSV 文件名 / 01 白名单路径段 指向同一组模块
- **§4.1/§4.2 反向校验**：登记为"已作废/本期修改"的 case_id 必须真在 snapshot 里（拦编号敲错/归错节）
- **auto:Y 耦合**：05 标 `auto:Y` 的行必须有非空 asset_path（防 06 C4 自动化覆盖率虚高）
- **快照元数据三方身份**：`_快照元数据.md` 的 CHG/基线/SHA ⟺ 包名/02 一致（**注意**：需先让 8.5 生成步把 CHG/基线写进元数据，否则会误报；当前 8.5 只写起包时间/源 commit/SHA）

> 这些都属"跨产物接缝"，与本清单同源；之所以不进 v1，是因为各自的误报面更大、或依赖尚未产出的字段。加任何一条前，先按本脚本的做法补正向/负向/故障注入三类自测进 `selftest.sh § G`。
