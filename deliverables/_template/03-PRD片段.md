## 三、详细需求

### 3.1 核心流程

> 用文字 + 序号清单描述。**不要塞图**（截图放 `attachments/`，文中链接）。
> 下面是占位示例流程，演示"列表 → 详情抽屉 → 提交动作"的写法，请替换为本项目真实流程。

1. 用户进入"<示例模块> → <列表页>"
2. 表格按"<某时间字段>"倒序，显示最近 24h 内的记录
3. 用户点击单条记录 → 弹出"<详情抽屉>"
4. 抽屉左侧展示<主内容区，例 地图 / 图表>（可交互）
5. 抽屉右侧显示记录元信息（<字段1> / <字段2> / <字段3>）
6. 用户判断后选择处理结论：`<结论A> / <结论B> / <结论C> / <结论D>`
7. 提交结论 → 抽屉关闭 → 列表对应行刷新状态
