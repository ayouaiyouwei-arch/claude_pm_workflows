### 13.5 自检命令（A1.5 起包前必跑）

```bash
DEMO=attachments/demo/index.html
COVERED=0
for kw in 'hover\|hover:' 'active\|active:' 'focus\|outline' 'disabled\|cursor-not' 'loading\|skeleton\|animate-pulse' 'empty\|暂无\|未找到' 'error\|失败\|错误\|重试' 'truncate\|min-w-0' 'onkeydown\|tabindex\|Esc\|Enter' 'transition\|duration-'; do
  COUNT=$(grep -E "$kw" "$DEMO" | wc -l | tr -d ' ')
  [ "$COUNT" -gt 0 ] && COVERED=$((COVERED + 1))
done
echo "覆盖 $COVERED / 10"
```

