## 六.5、视觉门槛（V，**仅 UI 类需求** = 包内有 `01.5-视觉规范.md`）

> 非 UI 类需求跳过本节。UI 类需求 V1-V5 与 F/C/Q/D 同级硬指标，任一不达标 = 一票否决。

| # | 项 | 标准 | 测试方式 |
|---|---|---|---|
| V1 | 截图相似度 | 与 `attachments/demo/screenshots/baseline-default.png` 相似度 ≥ **98%**（同时满足主流程 + 5 态 + 多断点全部 baseline） | Playwright `expect(page).toHaveScreenshot({ maxDiffPixelRatio: 0.02 })` |
| V2 | token 一致性 | 实测 `getComputedStyle` 取的颜色 / 字号 / spacing 与 `01.5-视觉规范.md § 一/二/三` 表内 token **100% 一致** | DevTools 取值 + 自动化断言 |
| V3 | 字号偏差 | 与 `01.5 § 二` 标注的 px 字号偏差 = **0px**（不允许 ±1px） | 同上 |
| V4 | 间距偏差 | margin / padding / gap 与 `01.5 § 三` 偏差 ≤ **2px**（v4 默认 4px 步长内） | 同上 |
| V5 | 暗色模式无破洞（如 `01.5 § 六` 标 "是"） | 切到 `prefers-color-scheme: dark` 无样式破洞、无对比度不足、无字符遮挡 | Playwright `colorScheme: 'dark'` + 截图比对 |

V1-V5 一票否决：任一项不达标，包不允许 `.active → .done`。

| C1 / Q1 不达标 | 一票否决 |
