## 五、读权限白名单（D3 升级 · 包外可读不可改清单）

> 默认 Codex 只能读本包内文件 + 第 § 三 修改白名单文件。本节是**例外**：以下包外路径**可读 + 可执行**（跑测试需要），但**不可改**（要改请 PM 另起 CHG 走流程）。

### 5.1 测试用例 CSV（仅作上游兜底参考；优先使用包内 snapshot）

```
test/test-cases/_用例字段说明.md          ← 优先用包内 snapshot 副本

```

> ⚠️ 优先级：**`./test-cases-snapshot/` > `test/test-cases/`**。包内 snapshot 是冻结的"事实源"。除非 `[BASELINE-DRIFT]` 异常，否则不读上游 CSV。

### 5.2 自动化资产（必读 + 必跑 + 不可改）

```
test/tools/api-collection/                ← Bruno 集合（含 environments / auth / <模块> 子目录）
test/tools/e2e-scripts/                   ← Playwright 项目（含 fixtures / utils / tests）
```

读它们是为了：跑 `bru run` / `pnpm playwright test`、查 spec 现状、判断 `05 § 二/三` 列出的 `asset_path` 是否真的存在。

**不可改**意味着：

- ❌ 不允许新增 `.bru` / `.spec.ts` 文件
- ❌ 不允许修改既有 `.bru` / `.spec.ts` / 任何 fixture / config
- ❌ 不允许 `pnpm install` 之外的 npm/pnpm 写操作
- ✅ 跑测试的"输出物"（screenshots / har / playwright-report 等）落到 `<本包>/evidence/`，不写回 `test/`

### 5.3 跑测试时的工作目录约定

```bash
# Bruno
cd test/tools/api-collection
bru run --env Local <本期模块> --reporter-json ../../reports/<B1.0.x>/bruno-results.json

# Playwright
cd test/tools/e2e-scripts
npx playwright test tests/regression/<本期模块>
```

> 跑完务必把 stdout/stderr 摘要追加到 `08-修复历史.md` 的 `[ROUND-N]` 段。

### 6.5 视觉契约铁律（仅 UI 类需求 · 包内含 `01.5-视觉规范.md` 与 `attachments/demo/` 时强制）

非 UI 类需求（包内无 `01.5-视觉规范.md`）跳过本节。

| # | 铁律 | 违规 = |
|---|---|---|
| 1 | **demo 是 100% 事实源** | `attachments/demo/index.html` 与 `01.5-视觉规范.md` 表内 token 是冻结契约。Codex 在 `code/` 内的实现必须像素级对齐 demo + 100% 引用 § 一/二/三 表内的 Tailwind class / token |
| 2 | **px 偏差硬指标** | 字号偏差 = 0px / 间距偏差 ≤ 2px / 圆角偏差 = 0 / 阴影偏差不允许（直接用 Tailwind class）。任一项超阈即 越界，标 `[VIOLATION-N]` |
| 3 | **token 引用不允许写死 hex** | 凡 `01.5 § 一` 表内已有的 token，代码必须用 Tailwind class（如 `bg-blue-500`）或 `@theme` 内品牌色 token；**不允许**直接写 `style={{ background: '#3B82F6' }}` |
| 4 | **不允许引入 § 四 表外的新组件 / 新依赖** | 严禁新增 UI 组件库（如 antd / mui / arco / chakra / radix / shadcn 等）。可复用的图标 / 组件库以 `01.5-视觉规范.md § 四` + `PROJECT-PROFILE.md § 五` 已声明的为准 |
| 5 | **5 态实现完整覆盖** | success / loading / empty / error / permission 5 态全部要写，每态必有 baseline 截图比对用例。跳过任一态 = 不合规 |
| 6 | **含糊处问 PM 不要自由发挥** | 实施时遇到 demo 没覆盖到的态 / 边界条件 / 暗色模式细节 → 写 `[QUESTION-N]` 段问 PM，**不**按个人审美补 |

> Codex 提交前自检：`grep -E "style=\{\{[^}]*background.*#[0-9a-fA-F]{3,6}" code/<本期改动文件>` 应为空（无内联 hex）。
