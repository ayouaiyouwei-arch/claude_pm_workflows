## 五、读取规则速记

```

1. 读 05-用例清单.md § 四（本期增删改登记）
2. 找该 case_id 是否在登记里？
   ├─ 在，标"已作废"  → 完全忽略
   ├─ 在，标"本期修改" → 只看 05 § 二/三
   ├─ 在，标"本期新增" → 只看 05 § 二/三
   └─ 不在            → 看 snapshot/<模块>.csv
3. 写代码 / 写测试断言时严格按上面的"事实源"
```

## 六、违例与异常处置

| 异常 | 处置 |
|---|---|
| snapshot 文件 SHA 与本表对不上 | 立即停止，写 `08-修复历史.md` `[BASELINE-DRIFT-N]`，等 PM 裁决 |
| snapshot 缺某模块 CSV | 同上 |
| `_快照元数据.md` 的"起包时间"晚于 `99-状态.md` 的 `.draft → .active` 时间 | 异常，立即停止 |
| Codex 修改了 snapshot 内任意文件 | commit 退回 + `[VIOLATION-N]` |
