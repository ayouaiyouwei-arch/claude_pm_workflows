> 本次需求涉及的所有 HTTP 接口契约。**Codex 必须以本文件为准生成 / 校验代码**；如发现实际后端与本文件不符，停下来标 `[CONTRACT-DRIFT]` 给 PM。

## 一、接口清单

| 编号 | 方法 | 路径 | 说明 | 是否新接口 |
|---|---|---|---|---|
| API-01 | GET | `/api/<模块>/<资源>` | `<列表>` | 新增 |
| API-02 | GET | `/api/<模块>/<资源>/{id}` | `<单条详情>` | 新增 |
| API-03 | GET | `/api/<模块>/<资源>/{id}/<子资源>` | `<某重内容序列>` | 新增 |
| API-04 | POST | `/api/<模块>/<资源>/{id}/result` | 提交处理结论 | 新增 |

---

## 二、鉴权

- **方式**：HTTP Header `Authorization: Bearer <jwt>`
- **角色**：所有接口需 `<角色A>` 或 `<管理员角色>`；`API-04` 额外需 `role.write=true`（角色清单见 PROJECT-PROFILE.md § 六）
- **失败码**：`401 Unauthorized`（未登录）/ `403 Forbidden`（已登录但无权限）

---

## 三、通用约定

| 项 | 值 |
|---|---|
| Content-Type | `application/json; charset=utf-8` |
| 时间格式 | ISO 8601，统一 `+08:00` |
| 分页 | `page` 从 1 起；`page_size` 默认 20，最大 100 |
| 错误结构 | `{ "code": <int>, "message": <string>, "request_id": <string> }` |
| 幂等 | 写接口需带 `X-Request-Id`（UUID v4），24h 内重复请求返回首次结果 |

## 四、详细契约

### API-01 GET `/api/<模块>/<资源>`

**请求 Query**

| 字段 | 类型 | 必填 | 默认 | 说明 |
|---|---|---|---|---|
| `page` | int | N | 1 | 页码 |
| `page_size` | int | N | 20 | 每页条数（≤ 100） |
| `<type>` | string | N | - | `<类型字段>`，多值用逗号分隔 |
| `status` | enum | N | - | `pending` / `closed` / `overdue` |
| `time_from` | datetime | N | -24h | 起 |
| `time_to` | datetime | N | now | 止 |

**响应 200**

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "total": 156,
    "page": 1,
    "page_size": 20,
    "items": [
      {
        "id": "1789012345678901234",
        "field_1": "<示例值 1>",
        "field_2": "<示例值 2>",
        "type": "<value_a>",
        "created_time": "2026-05-08T10:23:45+08:00",
        "metric": 42,
        "status": "pending",
        "result": null
      }
    ]
  }
}
```

**错误码**

| code | http | 含义 |
|---|---|---|
| 0 | 200 | 成功 |
| 40001 | 400 | 参数非法（page_size 超 100 等） |
| 40101 | 401 | 未登录 |
| 40301 | 403 | 角色不足 |
| 50001 | 500 | 服务异常 |

**响应 200**：返回单条记录完整信息（字段见 `03-PRD片段.md` § 3.2）

**错误码**

| code | http | 含义 |
|---|---|---|
| 40401 | 404 | 记录不存在 |

### API-03 GET `/api/<模块>/<资源>/{id}/<子资源>`

**响应 200**（占位示例：以"序列点"类重内容为例）

```json
{
  "code": 0,
  "data": {
    "id": "1789012345678901234",
    "series": [
      { "ts": "2026-05-08T10:23:40+08:00", "x": 116.397, "y": 39.908, "metric": 45 },
      { "ts": "2026-05-08T10:23:41+08:00", "x": 116.398, "y": 39.909, "metric": 42 }
    ]
  }
}
```

约定：`series` 数量上限 600 个点（=10min @ 1Hz）；超出由后端降采样。

---

### API-04 POST `/api/<模块>/<资源>/{id}/result`

**请求 Header**

```
Authorization: Bearer <jwt>
X-Request-Id: <uuid-v4>          ← 必填，幂等键
```

**请求 Body**

```json
{
  "result": "<result_a>",
  "result_remark": "<处理备注示例>"
}
```

**响应 200**

```json
{
  "code": 0,
  "data": {
    "id": "1789012345678901234",
    "status": "closed",
    "result": "<result_a>",
    "operated_at": "2026-05-08T10:35:12+08:00",
    "operator": "<操作人>"
  }
}
```

**错误码**

| code | http | 含义 |
|---|---|---|
| 40002 | 400 | result 枚举非法 / remark 超 200 字 |
| 40901 | 409 | 事件已是 closed 状态（幂等键不同） |
