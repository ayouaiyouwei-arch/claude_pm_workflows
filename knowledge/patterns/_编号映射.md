# patterns 编号双向映射表（主项目 ↔ pipeline-skeleton 骨架）

> **机制说明**。主项目与骨架的 P 编号是两套独立体系，历史上每次同步靠人肉对照（曾出过漏登类事故）。**本表是两套编号互译的唯一权威**——同步 patch 时照表机械替换，不再临场判断。
>
> 维护规则：① 任一侧新立 pattern → **当场登记本表**（含"仅单侧"行）② 本表双侧各放一份，同步 patch 时一并同步 ③ 编号永不重排（追溯链不断）。

## 三、同步 patch 时的使用方法

1. patch 文本中出现 `P0XX` 引用 → 查本表对应侧编号列 → 替换为另一侧编号；目标侧为 "—" → 把编号引用改为规则名全称（如 "（retrospect 滞后漏审）"）
2. 反向同理
3. 替换完跑一遍自检：`grep -oE "P0[0-9]{2}" <改动文件> | sort -u` 逐个对照本表确认归属正确
