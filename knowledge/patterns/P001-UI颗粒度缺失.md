# P001 · UI 改动颗粒度 / 位置 / 5 态描述缺失

## 描述

A1 产品专家产出 `01-需求细化.md` 时，对 UI 类改动只写 "在 XX 页加一个按钮" 这种**含糊描述**，未明确：

- 作用粒度：是页面级（一个按钮）/ 卡片级（每张卡都加）/ 行级 / 仅特定状态项？
- 位置：在该对象的什么位置（顶部 / 卡片右上角 / 操作列 ……）
- 5 态：默认 / 悬停 / 禁用 / 加载 / 操作成功
- 可见性条件：所有角色可见？某状态才出现？

直接结果：研发 / Codex 拿到 PRD 后会**误解为"每个小卡片上都加一个按钮"**（或反之），导致返工。
