# P011 · 视觉规范禁用模糊形容词 · 措辞与 demo 像素双重事实源

## 描述

A1.5 视觉规范专家用模糊形容词（"胶囊" / "气泡" / "椭圆" / "大致" / "类似"）描述视觉细节 → 在视觉规范 + Codex 提示词 + 测试用例 3 处重复 → Codex 阅读时**优先取文字描述**而非像素级对照 demo 截图 → 实施时按文字写错误 class（如 "胶囊" → `rounded-full` → 椭圆）→ 出 BUG。

**关键认知**：当文字与图片冲突时 · Codex（以及大多数研发）的解读路径是 "文字优先 → 图片是辅证" · 不是 PM 期望的 "图片是事实源 → 文字是注释"。**视觉规范不能依赖研发会像素级对照 demo** · 必须用并排对比 + 强约束措辞双重防御。

## 触发场景

A1.5 写视觉规范时 · 任一命中即触发硬约束：

1. 涉及圆角形态（rounded-* 各档）
2. 涉及阴影深浅（shadow-* 各档）
3. 涉及颜色饱和度 / 透明度
4. 涉及字号 / 行高 / 字重
5. 涉及间距 / 高度 / 宽度
