# P002 · PRD / 需求细化文档混入技术语言

## 描述

A1 产品专家产出 `01-需求细化.md` 时，混入了**本该在技术方案文档里出现**的内容：

- 代码路径：`code/<仓库名>/<前端包>/src/pages/xxx`
- URL 路由：`/admin/order/list`、`/dashboard/list`
- 接口名 / HTTP 方法：`POST /order/cancel`
- 文件名：`OrderCard.tsx`、`useOrderStore`
- 技术栈词汇：`React state`、`Vuex`、`gRPC stub`
- 数据库字段名 / 表名（拼音 / 英文蛇形）

直接结果：
- 评审人（产品 / 运营 / 测试）需要"翻译"才能看懂，效率低
- 需求与实现耦合，将来换栈 / 换前端框架时需求文档要同步改
- A3 技术方案专家无法在不重复的前提下产出"补充技术细节"——它的活被 A1 抢了
