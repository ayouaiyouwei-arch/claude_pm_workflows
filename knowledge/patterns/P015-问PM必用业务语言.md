# P015 · agent 向 PM 提问必用业务语言 · 禁技术黑话

## 描述

agent 在 Gate 1 / 1.5a / 2 / 3 / 打回时向 PM 提问的措辞**大量使用技术黑话**（`import.meta.env.PROD` / `shouldMockPath` / `hostname endsWith` / `Tailwind arbitrary value` 等），PM 看不懂 → 无法判断 → 决策卡住或拍错。

P002 已守"PRD 文档不能含技术语言" · 但 P015 是其**孪生兄弟**：**问 PM 时的问题文案**也必须用业务语言。

## 业务影响

- PM 看到"我应该选 A 还是 B"但完全看不懂 A/B 区别 → 决策延迟 / 决策错 / 信任流失
- 在长流水线中 PM 是唯一的"业务真相源" · 问题翻译不清 → 整条流水线 GIGO（垃圾进 / 垃圾出）

## 强约束（LOCKED）

任何 agent 向 PM 提出**任何问题清单**时必须满足 4 条：

### 1. 业务影响必先说

每个问题第一句必须以"用户/客户/演示场景的影响"开头 · **不允许**直接抛技术细节问。

❌ 错例：
> Q1: dev 灰度 `import.meta.env.MODE` 实际是什么？

✅ 对例：
> Q1: 矛盾点澄清（示例）—— 你在页面上看到 <现象A>（用户实际经历）· 但代码逻辑说"在 <某条件> 下 <现象A> 不应该出现"。这两件事矛盾。请你实测一下复现路径 · 或者直接选"<兜底路径：全场景统一处理 · 不依赖该条件的具体取值>"。

### 2. 技术词必括号翻译

如果绕不开技术词必须**括号注解业务含义** · 或干脆**用业务比喻替代**。

| 技术词 | 业务版翻译 |
|---|---|
| `import.meta.env.PROD` / `MODE` | "代码编译时的'线上模式'标记" |
| `shouldMockPath` / 拦截器 | "判断哪些网址要换成演示数据" |
| `hostname` | "当前网址的域名部分" |
| `endsWith` / `startsWith` | "网址以 XX 结尾 / 开头" |
| `Tailwind arbitrary value` / `rounded-xl` | "框架自定义尺寸写法 / 中等圆角" |
| `lazy import` / `Suspense` | "页面按需加载" |
| `SSR` / `hydration` | "服务端渲染相关" |
| `route guard` | "页面访问权限拦截" |
| `interceptor` / `middleware` / `mutator` | "请求中转站" |
| `schema` | "数据结构定义" |
| `API 端点` / `endpoint` | "后端数据接口" |
| `props` / `state` / `hook` | "前端组件内部变量" |
| `WebSocket` / `STOMP` / `SockJS` | "实时推送通道" |
| `polling` | "前端定时轮询" |
| `fallback` | "兜底数据" |
| `token` / `JWT claim` / `cookie` | "登录凭证 / 浏览器记忆" |
| `commit SHA` / `merge` / `rebase` | "代码版本号 / 合并" |
| `production build` / `vite build` | "生产环境的打包结果" |
| `useEffect` / `useMemo` | "前端组件生命周期 / 缓存" |
| `localStorage` / `sessionStorage` | "浏览器本地存储" |
| `axios` / `fetch` / `console.log` | "前端发请求的工具 / 浏览器调试" |

### 3. A/B/C 选项必各带业务后果

`AskUserQuestion` 给 PM 的每个选项 `description` 必须明确"如果选这个 · 用户会看到/经历什么 · 后果是什么"。

❌ 错例：
> A. 直接 404（path:'*' 走 ShellFallbackRedirect 兜底）

✅ 对例：
> A. 业务人员收藏夹里有老网址打开看到 404（系统自带兜底页 · 不会白屏 · 让用户重新选菜单）

### 4. 提问 prompt 完成后必跑 grep 自检

在 agent 返回给主对话/PM 之前 · 跑一遍黑名单 grep（命中 ≥ 1 即重写）：

```bash
# 30 词技术黑名单（不含中文翻译）
GREP_BLACKLIST="import\\.meta\\.env|shouldMockPath|hostname|endsWith|startsWith|Tailwind|arbitrary value|lazy import|Suspense|SSR|hydration|route guard|interceptor|middleware|mutator|schema|endpoint|props|hook|WebSocket|STOMP|SockJS|polling|fallback|token|JWT|claim|cookie|commit SHA|rebase|production build|MODE ===|void 0|undefined|query selector|dispatch action|useEffect|useMemo|localStorage|sessionStorage|axios|fetch|console\\.log|devtools"

# 期望：纯业务表达里命中数 = 0（含中文括号紧跟翻译的可放过）
```

### 5. 例外（白名单）

允许使用技术词 + 不必翻译的 4 类场景：
- ✅ 文件名（如 `01-需求细化.md` · 不需翻译）
- ✅ 路径（如 `code/<repo>/...` · 不需翻译）
- ✅ commit short SHA（如 `c198bc0f` · 不需翻译）
- ✅ 已被 PM 明确使用过的术语（如 PM 自己说"按 hostname 判断" 后 agent 可用此词）
