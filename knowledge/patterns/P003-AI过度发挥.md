# P003 · AI 过度发挥（PRD 未禁止 → AI 主动补衍生交互）

## 描述

与 P001（"该说没说"）不同，本模式是 **AI 过度发挥**：

- PRD 只说了"在列表 / 卡片上加 X"
- AI 看到现状（如"列表有 8 项，默认仅展示前 N 项"）后，**主动补**衍生交互（"展开全部" / "排序" / "筛选" / "批量操作" / "导出"等）
- 这些衍生交互**没在 PRD 里出现**，但也**没被 PRD 显式禁止**
- 结果：研发产出**功能溢出**，PM review 时才发现"我没要这个"

**核心机制**：AI 在补完信息缺口时，会基于"常见管理后台的标杆做法"做**假设性扩展**，而 PRD 没说"不要扩展"。

## 与 P001 / P002 的区别

| 模式 | 类型 | 表现 |
|---|---|---|
| P001 | 该说没说 | "在卡片上加按钮" → AI 默认每张卡都加 |
| P002 | 该写到别处的写在这 | PRD 混入代码路径 / 接口名 |
| **P003** | **该明禁却没禁** | PRD 没说"不要展开全部"→ AI 主动补"展开全部" |
